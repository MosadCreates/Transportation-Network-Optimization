# 🚀 Just Deployed: Cairo Smart City Transportation AI! 🚦

I'm incredibly excited to share my latest project—a complete algorithmic overhaul and AI integration for the Greater Cairo Metropolitan Area transportation network! 🌍🇪🇬

As part of my CSE112 Design and Analysis of Algorithms coursework, I tackled the massive challenge of urban congestion using a blend of theoretical computer science, machine learning, and modern web engineering.

### 🧠 Core Algorithmic Engineering:
- **Graph Theory & MST**: Implemented Kruskal’s Algorithm (with Union-Find) to design a cost-efficient infrastructure expansion, weighing population density against construction costs.
- **Advanced Pathfinding**: Built a side-by-side race between Dijkstra’s exact shortest path and an A* Heuristic Search for emergency vehicle preemption (achieving drastically lower ETAs!).
- **Dynamic Programming**: Solved complex 0/1 and Bounded Knapsack problems to optimize road maintenance budgets and bus fleet allocations for millions of daily riders.
- **Multimodal Routing**: Engineered an integrated transit network capable of routing users across Bus and Metro lines while calculating optimal transfer penalties.

### 🤖 Machine Learning Integration:
I didn't stop at classic algorithms. I integrated **scikit-learn** to train a Random Forest Regressor on temporal traffic data (using the Bureau of Public Roads formula). The model actively forecasts congestion ratios based on road capacity, condition, and time of day! 📈

### 🚢 Deployment & Docker:
To make this accessible, I wrapped the entire python backend into a beautiful, interactive **Streamlit** Web Dashboard. The app is fully containerized using **Docker**, meaning it runs identically anywhere, anytime.
